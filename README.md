# vco-home-layers

Home page prototype for VCO, Registered Valuers, in the Layers brand direction (concept C, "Monumental mark").

A single static page with no build step and no framework: `index.html`, one stylesheet, one small script and two subsetted variable fonts. Open `index.html` through any static server, or publish with GitHub Pages from the `main` branch root.

## What's in it

- The full-width VCO mark as the masthead. Its six layers build in once per browser session.
- A sticky header that swaps the "Registered Valuers" descriptor for the small logo once the masthead scrolls away.
- The layer index in the header, filling as you read down the page.
- Section rules that draw themselves once as they come into view.
- Service names that widen slightly on hover, using Archivo's width axis.
- A phone menu, a hairline contact form with a confirmation state, and the Tauranga local time in the footer.
- A night version that follows the device's dark mode, with the mark's pink first layer.
- Pink keyboard focus rings (paper on blue), and all motion off for anyone who has asked their device to reduce it.

## Placeholders

The phone number, email, address and property type list are placeholders. The contact form doesn't send anything; it shows its confirmation state and says so.

## Fonts

Archivo and Martian Mono, both under the SIL Open Font License, subset to Latin and limited to the weights and widths used.
